2 SHIP 2 HARKINIAN FOR SWITCH 2 - v1.1
======================================

Unofficial port for a Switch 2 that can run homebrew.


WHAT'S NEW IN v1.1
- Less stutter in cutscenes and new areas.
- Nintendo button names in the controls menu.
- Clearing or resetting controls no longer freezes the game.
- A clear message if game files are missing, and a reminder that - opens the
  menu.
- With right stick aiming on, moving the stick no longer leaves first person.
See CHANGELOG.md for the full list.


INSTALL
1. Copy the "switch" folder to the root of your SD card, replacing old files.

2. Already have mm.o2r from the pre-release? Keep it.
   Otherwise, make it from your own US ROM by following GAME-DATA.md.

3. Check that /switch/2s2h/ has:

     2ship.nro
     2ship.o2r
     mm.o2r

4. Start "HarbourMasters - 2Ship" from the homebrew menu.
   The first launch takes longer while it prepares shaders.


CONTROLS
  Switch 2 button     Game button
  B                   A
  Y                   B
  A                   C-Down
  X                   C-Left
  R                   C-Right
  ZL                  Z
  ZR                  R
  Right stick         C buttons
  -                   Open the menu

Gyro aiming: turn it on in Enhancements > Camera > Gyro Aiming.


REPORTING A BUG
Say what you were doing, and include the /switch/2s2h/logs/ folder.
Do not share your ROM or mm.o2r.
