2 SHIP 2 HARKINIAN FOR SWITCH 2 - TEST BUILD (2026-11-22)
=========================================================

This is an unofficial pre-release for testing. It runs as homebrew on a
Nintendo Switch 2. Expect bugs, and keep a copy of any saves you care about.

NEW IN THIS BUILD
- Fixed the missing, quiet or broken music and sound.
- Fixed the crash about 45 seconds into the title sequence.
- Fixed several other memory bugs in the audio code.
- Up to date with the main 2 Ship 2 Harkinian development line, including
  Faster Hookshot and saving on the moon.

Performance is not finished: some areas still lag. That is the next thing
being worked on.


WHAT YOU NEED
- A Switch 2 that can run homebrew.
- A computer (Windows, macOS or Linux).
- Your own dump of the US version of Majora's Mask (N64 or GameCube).

The game's data is NOT included. You make it once from your own ROM.


INSTALL
1. Copy the "switch" folder from this zip to the root of your SD card.
   If it asks, merge the folders and replace the old files.

2. Make mm.o2r from your ROM. GAME-DATA.md has the step-by-step guide.
   If you already made mm.o2r for the 2026-11-18 test build, keep using it.

3. Put mm.o2r in /switch/2s2h/. The folder should now have:

     /switch/2s2h/2ship.nro
     /switch/2s2h/2ship.o2r
     /switch/2s2h/mm.o2r

4. Start "HarbourMasters - 2Ship" from the homebrew menu.


CONTROLS
  Switch 2 button     Game button
  B                   A
  Y                   B
  A                   C-Down
  X                   C-Left
  R                   C-Right
  ZL                  Z
  ZR                  R
  Right stick         C buttons
  -                   Open the menu

If you played an earlier build, your saved controls stay. To get these, reset
them in the input editor in the menu.

To quit, use the power button at the top of the menu, or close the game from
the HOME menu.

For 120 FPS on the Switch 2 screen, raise the FPS slider in the graphics
settings above 60. Most TVs stay at 60.


REPORTING A BUG
Please include:
- What you were doing, and where in the game.
- Whether the game crashed, froze, or kept running.
- The /switch/2s2h/logs/ folder from your SD card.

Send your report to whoever shared this test build with you, or where you
downloaded it.

Do not share your ROM or mm.o2r when you report a bug.
