2 SHIP 2 HARKINIAN FOR SWITCH 2 - v1.0 PRE-RELEASE 2
====================================================

Unofficial test build for a Switch 2 that can run homebrew. Back up any saves
you care about. See CHANGELOG.md for what's new.


INSTALL
1. Copy the "switch" folder to the root of your SD card, replacing old files.

2. Already have mm.o2r from v1.0 Pre-Release? Keep it.
   Otherwise, make it from your own US ROM by following GAME-DATA.md.

3. Check that /switch/2s2h/ has:

     2ship.nro
     2ship.o2r
     mm.o2r

4. Start "HarbourMasters - 2Ship" from the homebrew menu.
   The first launch takes longer while it prepares shaders.


CONTROLS
  Switch 2 button     Game button
  B                   A
  Y                   B
  A                   C-Down
  X                   C-Left
  R                   C-Right
  ZL                  Z
  ZR                  R
  Right stick         C buttons
  -                   Open the menu

Gyro aiming: turn it on in Enhancements > Camera > Gyro Aiming.


REPORTING A BUG
Say what you were doing, and include the /switch/2s2h/logs/ folder.
Do not share your ROM or mm.o2r.
